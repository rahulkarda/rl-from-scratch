# rl-from-scratch

Implementing classic reinforcement learning algorithms from the ground up. No stable-baselines, no high-level wrappers — just PyTorch and Gym.

## Goals

- Understand each algorithm by writing it (not reading it)
- Match published reward curves on standard envs
- Keep each algorithm in a single readable file
- Document hyperparameter choices and what actually mattered

## Status

Just starting. See [ROADMAP.md](ROADMAP.md).

## Setup

```bash
pip install -r requirements.txt
```
